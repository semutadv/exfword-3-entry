One word from your ex. This entry picks the shortest complete sentence an
ex can send: one letter that acknowledges your whole paragraph, answers
none of it, and has ended more conversations than any argument ever
written. If you have received it, no explanation is needed. If you have
not, you will.

`main.ts` (Node 22, no dependencies) writes the word to `entry.txt` in the
output directory, clearing the directory's contents first and adding no
trailing newline.
